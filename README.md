# Strength v0.2.0

## Highlights
- One exercise per workout screen
- V1-compatible weight/history storage keys
- Automatic warm-up suggestions
- One-tap set completion with Edit when needed
- 3-minute default rest for heavy compounds
- 2-minute demanding accessory rest
- 90-second accessory rest
- +30 sec and Skip controls
- Ping/vibration attempt at rest completion
- Plate calculator
- Technique cues
- Workout history and notes
- Monday Front Plank, Tuesday Seated Dip Machine, Thursday Chest-Supported Row Machine
- PWA/offline foundation

## Important iPhone 6 note
Older iOS/Safari may suspend browser JavaScript and sound while another app is in the foreground. Test the ping/vibration while Facebook is open. If iOS suppresses it, native packaging may eventually be required for reliable background alerts.
