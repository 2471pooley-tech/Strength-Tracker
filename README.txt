Strength & Conditioning Tracker - iPhone 6 MVP

How to use:
1. Put index.html on any simple web host, or open it from a local web server.
2. On the iPhone 6, open the page in Safari.
3. Use Share > Add to Home Screen for an app-like icon.
4. Workout data is stored locally in Safari on that phone.

Current features:
- 5-day program
- Monday planks instead of hanging leg raises
- Tuesday seated dip machine
- Thursday chest-supported row machine
- StrongLifts-style warm-up suggestions
- Automatic +5 lb progression after successful strength targets
- Double-progression logic for accessories
- Rest timer
- Workout notes and history
- Starting-weight setup

This MVP intentionally avoids modern JavaScript features for older Safari compatibility.
